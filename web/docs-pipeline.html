Modules as separate processes

acq ─[WS01 spectrum frames]─> core ─[depth trace]─> features ─[8-dim vec]─> ai ─[verdict]
        TCP binary framing, little-endian, per-hop latency stamps
  • acq (crate sim) — simulated sensor, ring-sourced spectra.
  • core (crate core) — the FFT pipeline (this code also runs in your browser via WASM).
  • features (crate features) — documented physics-based features: mean/std/min/max, penetration ratio, spatter rate, pore count, humping index.
  • ai (crate ai) — softmax over learned linear weights; optional ONNX plug-in path for bring-your-own models.

Wire format

Frames are magic-prefixed (WS01), length-prefixed, little-endian, with sequence + origin timestamp preserved along the whole chain — see docs/wire-format.md. End-to-end latency is measured as now − ts_ns and reported as mean/p50/p99.

Why Rust here

The depth profile needs one FFT per A-scan at up to hundreds of kHz — a memory-safe system language with zero-GC, deterministic latency and lock-free streaming is a natural fit; the identical crate compiles to WASM for the in-browser demo.
